## Known suspects
1. CONFIRMED - Save As preserves old "Untitled video" document name - native/src/editor/project.cpp:308-324 - `Project::saveAs` updates `path_` on disk but never updates `bundle_.doc.project.name` to match target file base name
2. CONFIRMED - Placed/imported agent clips are hardcoded to "clip" - native/src/engine/cmd_edit.cpp:85 - Clip insertions in `cmd_edit.cpp`, `cmd_assemble.cpp:284`, and `cmd_storyboard.cpp:341` use `Labels{QStringLiteral("clip")}` instead of `asset->originalName`
3. CONFIRMED - Undo group labels echo raw chat text instead of describing edit - native/src/agent/agent_harness.cpp:447 - `AgentHarness::executeTurn` sets undo group label using `QStringLiteral("%1: %2").arg(dirCap, userMessage)` before running tools; should summarize actions taken
4. CONFIRMED - Director skips titles because tool domain is locked out and unprompted - native/src/agent/specialist.cpp:231-241 - `title.apply` is registered under domain `"style"` and `text.add` under `"editor"`, both excluded from Director's allowed mutating domains
5. NOT A BUG - 10-bit H.264 HDR is rejected and SDR emits warnings - native/src/export/export_settings.cpp:245 - `validate()` strictly errors on 10-bit H.264 HDR; `exporter.cpp:314` and `export_cli.cpp:291` log explicit warnings for 10-bit SDR NVENC fallback
6. NOT A BUG - GPU encoder checkbox is disabled for non-H.264/HEVC formats - native/src/app/ExportDialog.qml:134 - `enabled: !root.ex.running && (formatBox.currentText.startsWith("H.264") || formatBox.currentText.startsWith("HEVC"))` disallows checking NVENC for ProRes, DNxHR, or WAV
7. NOT A BUG - Export uses libswscale auto-threading and GPU rendering - native/src/export/exporter.cpp:376 - Frame convert 4-thread clamp is preview-only (`frame_convert.cpp:11`); export sets `sws_->threads = 0` for auto-threading and QRhi compositing runs on dedicated GPU thread
8. CONFIRMED - Comfy template directory has only a README and no JSON files - native/src/engine/comfy_templates/README.md:1 - `comfy_templates/` contains zero workflow definitions, leaving template discovery empty on fresh clones
9. NOT A BUG - Engine dynamically injects session property into all schemas - native/src/engine/engine.cpp:177-184 - `Engine::registerCommand` appends `"session": {"type": "string"}` to every command's `inputSchema.properties` prior to validation
10. CONFIRMED - Cross-session agent conversation history is purely in-memory - native/src/agent/specialist.h:60 - `history_` is stored in an ephemeral `std::vector<ChatMessage>` on the `Specialist` object that discards all state when the engine session terminates
11. CONFIRMED - Router client defines downloadUrl but collect leaves raw URLs without downloading - native/src/engine/cmd_comfy.cpp:2804-2852 - `ComfyRouterClient::downloadUrl` (`comfy_router_client.cpp:202`) is orphaned and `generate.router.collect` stores remote URLs in project without downloading media files locally
12. NOT A BUG - Timeline zoom divide-by-zero guard and export backdrop pause verified - native/src/app/timeline_view.cpp:567-598 - `paintClip` guards `tileW < 1` and crops thumbnails to aspect ratio; `CommandBar.qml:81` pauses timer when `appEditor.exporter.running` is true

## New findings (ranked, most user-visible first, max 25)
- [HIGH] Audio specialist blocked from placing audio clips on timeline - native/src/engine/cmd_edit.cpp:306 - Calling `audio.add` from Audio specialist fails permission check because command is registered under `"editor"` domain while specialist only has `"audio"` - Re-register `audio.add` under domain `"audio"` - effort S
- [HIGH] Title and style recipe commands unreachable by any agent - native/src/engine/cmd_titles.cpp:490 - `title.apply` and `recipe.apply` are registered under mutating domain `"style"`, but no specialist has `"style"` in allowed domains, preventing agents from styling - Add `"style"` to Director and Colorist allowed mutating domains - effort S
- [HIGH] agent.specialists command fails schema validation when called with "all" parameter - native/src/agent/agent_harness.cpp:680-683 - Schema defines empty properties with `additionalProperties: false`, rejecting `{"all": true}` calls from UI or CLI with `invalid_params` - Add `"all": {"type": "boolean"}` to `agent.specialists` inputSchema - effort S
- [HIGH] Null dereference crash in music.structure on deleted or invalid asset - native/src/engine/cmd_audio.cpp:565 - If a clip lacks an asset or points to an invalid ID, dereferencing `p.asset(*item->assetId)` crashes the application - Check `item->assetId` and nullity of `p.asset(...)` before dereference - effort S
- [MED] Open project cannot be renamed from Home screen and editor lacks rename UI - native/src/app/editor.cpp:630-633 - Home dialog blocks renaming open project ("Open projects are renamed from the editor"), but editor top bar has no rename input - Add project rename field in InspectorPanel project section - effort M
- [MED] Canvas preset buttons generate two disjoint undo steps - native/src/app/InspectorPanel.qml:549-552 - Clicking 16:9, 9:16, or 1:1 preset fires two distinct `editProject` commands for width and height, requiring two Ctrl+Z presses to undo - Combine canvas dimension changes into a single atomic command or undo macro - effort S
- [MED] project.open rejects file:// URI paths with not_found error - native/src/engine/cmd_session.cpp:113 - `QFileInfo::exists(path)` fails on raw file URIs provided by system drag-and-drop or file pickers - Convert `path` with `QUrl(path).toLocalFile()` when path starts with `file://` - effort S
- [MED] Leftover stderr debug print in production ComfyUI asset import - native/src/engine/cmd_comfy.cpp:1356-1358 - `fprintf(stderr, "DBG: after import\n"); fflush(stderr);` writes noisy debug messages to terminal output on every generation import - Remove the DBG fprintf call - effort S
- [MED] Settings comfy/autoStart and jobs/modelsDir read but never written - native/src/comfy/comfy_process.cpp:98 - Settings are read from QSettings on startup but no engine command or UI panel exposes them to user - Expose Comfy auto-start and models directory in Settings dialog - effort M
- [MED] Variable frame rate media drifts out of audio sync during timeline preview - native/src/media/demuxer.cpp:112 - Demuxer calculates packet timestamps assuming fixed frame duration, causing playback desync on VFR clips - Use container PTS timestamps directly and warn if VFR detected - effort M
- [LOW] Export dialog leaves bit depth selector enabled during audio-only export - native/src/app/ExportDialog.qml:175 - Selecting WAV or MP3 export leaves video bit-depth dropdown visible and editable, creating confusion - Hide video codec and bit-depth controls when format is audio-only - effort S
- [LOW] Track lock state ignored by split and ripple edit commands - native/src/engine/cmd_edit.cpp:182 - Splitting clips or running ripple edits does not check `track.locked`, allowing locked tracks to be mutated - Check `track.locked` in edit commands before modifying clips - effort S
